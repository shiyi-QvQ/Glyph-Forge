# Glyph Forge（造字）

作者：**十一**

一个 Fabric 模组：把方块缩小成可以自由调整尺寸的“微型方块”，再用这些小方块拼出任意文字。
不用再受“一格只能放一个方块”的限制——一个 `3×3` 的空间也能写出完整的「我」字。

> 一个文字方块本身仍然只占一格，但它的模型由成百上千个可缩放的小立方体组成，
> 所以文字可以远远超出单格方块的粒度。

## 功能

- **快捷键打开编辑器**：默认按 `K` 直接打开类似 Axiom 的编辑界面，不需要物品、不需要先放方块。
- **准星选择生成位置**：在编辑器里点“选择位置”，微型方块预览会跟随准星移动；
  左键确认、右键取消，也可以直接用 `X / Y / Z` 微调坐标并旋转朝向。
- **任意 Unicode 文字**：中文、英文、日文、韩文、表情符号等都可以。
- **外部字体**：点击“选择文件”加载 `.ttf`、`.otf`、`.ttc`、`.otc` 字体。
  Windows 下使用系统原生文件选择窗口，不受游戏内 AWT 无界面模式影响。
  只有编辑文字的客户端需要字体文件；字形会栅格化后同步给所有玩家。
- **填充方块取自背包**：编辑器扫描玩家背包（含副手）里的所有方块，点方块图标即可选用。
  支持原版与模组方块，不消耗物品。
- **不限行数、不限字符数**：想写多长就写多长，编辑器不再有 4 行 / 64 字限制。
  极长的文字仍会受 4096×4096 位图安全上限保护，避免一次占用过多显存。
- **单字大小**：文字输入框下方可以用 `◀ / ▶` 选中任意一个字，再用 `− / +` 单独放大或缩小它
  （0.25×–4.00×）；点击中间的标签即可恢复为 1.00×。同一段文字里可以混排大字和小字。
- **可调参数**
  - 字体分辨率（12–128 像素）
  - 单个小方块的尺寸（0.004–0.25 格）
  - 文字厚度 / 深度
  - 小方块之间的间隙
  - 加粗、斜体、合并优化
- **更精细的字形**：栅格化时最高使用 3× 超采样后再按覆盖率取点，
  小字号下的圆弧、撇捺和对角线更平滑，不再有明显锯齿。
- **附着于方块表面**：开启“附着方块表面”后，准星对准任意方块的水平侧面，
  文字会贴着墙面生成，像海报一样贴在方块表面，而不是悬空立在旁边。
- **历史记录**：每次生成 / 应用文字都会自动记入本地历史（最多 60 条，自动去重）。
  点击“历史记录”可以浏览、载入之前的文字与全部参数，也可以单条删除或清空全部。
- **实时预览**与方块数量统计。
- **合并优化**：相邻像素合并成大长方体；填充像素超过 1500 时自动启用，避免长文本卡顿。
- **多人游戏**：服务器保存并同步最终的方块矩形数据，其他玩家不需要安装相同字体。

## 使用方法

### 快捷键（推荐）

1. 进入世界，按 `K` 打开编辑器。
   - 准星指向已有的文字方块时，编辑该方块。
   - 否则会在准星前方寻找可替换的位置创建新的文字方块。
2. 在“生成位置”一栏确认坐标与朝向：
   - 点“选择位置”回到世界，微型方块预览会跟随准星；左键确认、右键取消。
   - 也可以用 `− / +` 按钮微调 `X / Y / Z`，点朝向按钮循环切换四个水平方向。
   - 需要贴墙时打开“附着方块表面”，再点“选择位置”：准星对准方块侧面即可自动贴合，
     文字背面紧贴墙面，朝向由墙面决定。
3. 输入文字，选一种背包里的方块作为填充材质；需要的话点击“选择文件”加载外部字体。
   想突出某个字时，用 `◀ / ▶` 选中它，再用 `− / +` 单独调整大小。
4. 调整分辨率、尺寸、厚度、间隙等参数，点击“生成”/“应用”。
5. 之后对着文字方块按 `K`，或空手右键，继续编辑。
6. 想复用以前的文字，点底部的“历史记录”：点击任意一行即可把它的文字和参数载入编辑器，
   右侧的“删除”移除单条记录，“清空全部”需要再点一次确认。

`K` 可以在“选项 → 控制 → 按键绑定 → 自定义文字”中修改。
如果准星前方没有可放置的位置，会提示“这里没有可以放置文字方块的空间”。
创建时如果所选坐标已被占用，编辑器会提示并建议微调坐标。

### 没有物品配方

本模组不会往创造模式物品栏或合成表里添加“文字方块物品”。
文字方块只能通过快捷键创建，生成后本身不可见、无碰撞、不阻挡视线；
它只是一个承载文字的锚点，真正显示的是成百上千个微型方块。

## 关于 3×3 的限制

传统方式里，一个方块的最小单位就是一格，`3×3` 只有 9 个位置，写不出复杂的汉字。
本模组把每个方块拆成可任意缩放的小立方体：文字的每一个像素都是一个独立的小方块，
因此实际可用的“像素”数量由字体分辨率决定，而不是由世界网格决定。

例如默认设置下，一个约 24 像素高的「我」字大约占 1.5–2 格宽、2 格高，
完全放得进 `3×3` 的墙面，并且笔画、留白都能保留。

## 性能说明

- 默认的“独立”模式每个像素渲染一个六面小方块，适合短文字。
- 开启“合并优化”后，相邻像素会合并成较大的长方体，视觉效果基本一致但性能更好。
- 当填充像素超过 1500 个时，渲染器会自动改用合并模式；单块文字最多保存 20000 个矩形。
- 位图尺寸上限为 4096×4096，避免超长文字或异常字体文件产生过大的数据。
- 字形渲染会根据尺寸自动选择 1× / 2× / 3× 超采样；文字越大越少用超采样，兼顾精度与内存。

## 构建

需要 **JDK 21+** 编译目标；由于 Loom 1.19 本身要求较新的 JVM，建议使用 **JDK 25 或更高版本**运行 Gradle。

```bash
# Windows（Git Bash / PowerShell 均可，确保 JAVA_HOME 指向 JDK 25+）
./gradlew build
```

产物：

```
build/libs/glyph-forge-1.0.0+1.21.11.jar
```

发布到 Modrinth 时上传这个 jar（不要上传 `-sources.jar`），并填写：

| 字段 | 值 |
| --- | --- |
| Project name | Glyph Forge |
| Slug | glyph-forge |
| Game version | 1.21.11 |
| Loader | Fabric |
| License | Apache License 2.0 |
| Environment | Client and server |

项目图标使用 `release/modrinth/icon.png`（512×512），说明文字可直接使用本 README。

重新生成模组图标（`GLYPH FORGE` 英文像素字标，同时输出 SVG 和 PNG）：

```bash
node tools/gen-icon.js
```

开发环境运行客户端：

```bash
./gradlew runClient
```
